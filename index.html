Firebase Setup Required

This app uses Firebase Firestore as its database. You need to create a free Firebase project and paste the config into this HTML file before the app will work.

  1. Go to console.firebase.google.com and create a new project
  2. Click Build → Firestore Database and create a database in test mode
  3. Go to Project Settings → Your apps → Add web app
  4. Copy the firebaseConfig object
  5. Open this HTML file and replace the FIREBASE_CONFIG values at the top of the <script> section
  6. Re-open the file — it will auto-seed the default users and settings
